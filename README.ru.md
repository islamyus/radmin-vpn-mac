# Radmin VPN Mac

**Нативный клиент macOS для существующих сетей Radmin VPN.**

Оболочка на SwiftUI, движок на Rust/OpenRad и виртуальный адаптер macOS.
Wine, CrossOver, Rosetta и Windows-службы для работы не нужны.

[English](README.md) · [Скачать](https://github.com/islamyus/radmin-vpn-mac/releases) · [Сборка](docs/building.md) · [Решение проблем](docs/troubleshooting.md)

Независимый общественный проект, не официальный продукт Famatech.
Проверенная платформа — Apple Silicon, macOS 14+. Сборки подписаны локальным
сертификатом; Apple Developer ID и notarization пока отсутствуют.

## Возможности

- Вход в существующие закрытые сети Radmin VPN вместе с Windows-компьютерами.
- Прямые TCP/UDP-соединения и соединения через relay.
- Передача IPv4 через utun, Ethernet/ARP-преобразование, MTU 1500.
- Компактное знакомое окно: группы сетей, IP участников, независимое выделение,
  светлая/тёмная тема и реальная задержка защищённого канала.
- Секрет устройства — в Связке ключей macOS; пароль сети приложение не сохраняет.
- Однократная установка ограниченной службы адаптера вместо sudo при каждом подключении.
- Отдельный тест скорости Mac ↔ Windows с проверкой целостности SHA-256.

## Установка

1. Скачайте DMG в [Releases](https://github.com/islamyus/radmin-vpn-mac/releases)
   и перенесите **Radmin VPN.app** в **Программы**.
2. Откройте приложение, нажмите кнопку питания и подтвердите первую установку
   службы адаптера в системном диалоге. Связка ключей может отдельно запросить
   доступ к устройству, особенно при переходе со старой сборки.
3. Выберите **Сеть → Присоединиться к сети…**, введите название и пароль общей
   сети Radmin и дождитесь соединения с участниками.

Повторный вход использует прежнее устройство и сохранённое сервером членство.
Запрос администратора и запрос Связки ключей — разные разрешения macOS.

## Minecraft Java

На компьютере, где запущен мир: **Esc → Открыть для сети**. Запомните порт из
сообщения в чате. На втором компьютере: **Сетевая игра → Прямое подключение**,
адрес **`IP_хоста_из_Radmin:порт_мира`**. Версии игры и наборы модов должны совпадать.
Автопоиск LAN-миров через виртуальную сеть не гарантирован; используйте IP и порт.

## Сборка

Нужны Xcode/Swift 6, Rust 1.95+, Python 3 и macOS 14+:

```sh
git clone https://github.com/islamyus/radmin-vpn-mac.git
cd radmin-vpn-mac
zsh scripts/build-dmg.sh
```

Готовый образ и `.app` появятся в `dist/`. Для запуска собранного приложения
Rust и Python не требуются. Подробнее — [инструкция сборки](docs/building.md).
Сборка автоматически использует установленный SDK, без привязки к версии Xcode.

Проверки:

```sh
swift test
cargo test --manifest-path native/Cargo.toml --locked
cargo test --manifest-path vendor/openrad/Cargo.toml --lib --locked
```

## Проверки и ограничения

С настоящим Windows Radmin проверены закрытый вход, прямые TCP/UDP и relay,
ping, MTU 1500, передача данных в обе стороны с SHA-256 и Minecraft Java.
Пользователь подтвердил работу через раздачу телефона и отдельный VPN.
Условия NAT, внешнего VPN и брандмауэра влияют на задержку и скорость.

Поддерживается IPv4; IPv6, произвольный Ethernet и часть функций Windows-клиента
пока отсутствуют. Интерфейс на русском. Intel не прошёл реальные проверки
совместимости. Не все режимы и сетевые окружения испытаны.
