САМОСТОЯТЕЛЬНАЯ ПРОВЕРКА RADMIN VPN (Mac Apple Silicon + Windows)

1. Распакуйте этот архив на Mac и на Windows.
2. На ОБЕИХ машинах включите обычный VPN и Radmin. Войдите в одну сеть Radmin.
3. На Windows дважды откройте Start-Windows-Test.cmd.
   Введите реальные Radmin IP Windows и Mac, показанные в приложении.
   Дождитесь Ready и оставьте окно открытым. Сервер остановится через 10 минут.
4. На Mac дважды откройте Start-Mac-Test.command.
   Подтвердите Radmin IP Mac/Windows и подпишите условия: например VPN-on-both.
5. Дождитесь окончания. Папка Reports рядом с тестом содержит:
   - Результат.txt: скорость в обе стороны, потери и задержка до/под/после нагрузки;
   - report.json: подробные результаты, маршруты и доступные счётчики движка;
   - initial.json: начало проверки, даже если её пришлось прервать.

Тест: два прохода по 4 МиБ в каждую сторону, SHA-256 для каждой передачи,
UDP-пакеты 1200 байт. Обычно несколько минут, общий предел около 8 минут.
Ответ UDP ожидается 1,5 секунды; более поздний ответ считается пропущенным.
Паузы TCP допускаются до общего предела передачи (3 минуты на направление).
На Mac не нужны Python, Homebrew или права администратора для самого теста.
Windows использует штатный PowerShell/.NET. Пароли и реальные файлы не нужны.
Тест не меняет маршруты, firewall, режим VPN, политику PowerShell или защиту ОС.

Если Windows спросит доступ для PowerShell в брандмауэре, решение принимается
локально для этого приложения. Не отключайте брандмауэр целиком. Если появится
красная ошибка без Ready, сохраните её; не считайте это работающим сервером.
Если система блокирует запуск файла, сохраните точный текст ошибки.

Если порт уже занят (already in use), возможно, прежний тестовый сервер ещё
работает в другом окне PowerShell. Если там было Ready, оставьте это окно
открытым и запускайте тест на Mac. Для перезапуска закройте только прежнее
окно тестового сервера и запустите Windows-тест снова. Другие программы
останавливать не нужно. Новый сервер пишет Ready только после открытия и TCP,
и UDP; неудачный запуск освобождает уже открытые им сокеты.

Для сравнения запускайте отдельные проверки с разными названиями условий:
VPN-on-both, VPN-only-Mac, VPN-off. Это не требуется для обычной проверки.
Какой-либо VPN тест самостоятельно не выключает.

Скорость зависит от маршрута и обоих интернет-каналов. Нулевые потери до
нагрузки не означают нулевые потери под нагрузкой: смотрите все три строки UDP.
В отчёте Windows VPN отмечен вашим названием условий; Mac не может проверить
настройки Windows автоматически. Счётчики движка доступны при запуске нового
Radmin-клиента на этом Mac; они не содержат паролей, ключей или содержимого пакетов.

Расширенный запуск из Terminal (пример):
./radmin-network-test --source 26.0.0.1 --peer 26.0.0.2 --mib 16 --rounds 1 --label VPN-on-both
Адреса в примере замените реальными адресами ваших устройств.

Исходники: native/src/network_test.rs и tools/windows/Start-RadminNetworkTest.ps1.
